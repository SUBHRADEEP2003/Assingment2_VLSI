Overview

This project implements a 4-bit Ripple Carry Adder (RCA) using Verilog HDL. The ripple carry adder is one of the most fundamental arithmetic circuits in digital electronics, demonstrating how multi-bit binary addition is performed using cascaded 1-bit full adders.
.

Objectives
  Design a 1-bit Full Adder using logic gates
  Build a 4-bit Ripple Carry Adder using structural modeling
  Simulate the design using a Verilog testbench
  Analyze propagation delay and critical path
